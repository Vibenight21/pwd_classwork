The Purpose of HTML is:

The purpose of HTML (HyperText Markup Language) is to structure and organize content on web pages.

To Make a Table, Follow This Procedure

  1. Write a table tag <table>
  2. Write a tr tag <tr>
  3. Write a th tag for each header colum< th>
  4. Write the text for each header inside the <th> tags
  5. Write the closing <tr> tag
  6. Write a table row tag and make the td tags
  7. Write the data inside the td tags
  8. Write a closing tr tags
  9. Write the closing table tag
